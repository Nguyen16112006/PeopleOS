# Ảnh chụp màn hình

Thư mục này chứa ảnh minh họa cho README/bài thuyết trình. **Chụp từ hệ thống đang chạy thật** (không dùng ảnh mô phỏng).
Đặt tên theo bảng dưới (PNG, rộng ≥ 1280 px, che dữ liệu nhạy cảm) rồi tham chiếu trong README.
