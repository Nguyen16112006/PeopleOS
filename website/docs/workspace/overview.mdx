HR Workspace API là REST API của **BFF** (Spring Boot, `apps/people-workspace/bff`). Đây là nơi duy nhất thực hiện **thao tác ghi** nghiệp vụ: mọi bước duyệt, kiểm tra quyền, ghi audit log và gửi thông báo đều diễn ra ở đây. Để **đọc** danh sách (đơn của tôi, hàng chờ duyệt…), dùng [GraphQL](../graphql.mdx).

```text
Base URL:  http://localhost:9080/api
Header:    Authorization: Bearer <JWT realm peopleos>
           Content-Type: application/json
```

:::info Khi nào dùng API này?
Đây là API của **ứng dụng HR first-party** (People Workspace) với quy trình duyệt 6 vai trò đầy đủ. Nếu bạn là developer xây ứng dụng riêng bằng API key, hãy bắt đầu từ [Platform API](../platform/overview.mdx) và [Bắt đầu nhanh](../getting-started.mdx).
:::

## Lấy token để thử

Tài khoản demo dùng chung mật khẩu `Peopleos@123` (**chỉ để demo**): `admin`, `hr`, `manager`, `director`, `accountant`, `employee`, `employee2`.

```bash
TOKEN=$(curl -s -X POST http://localhost:8080/realms/peopleos/protocol/openid-connect/token \
  -d grant_type=password -d client_id=people-workspace \
  -d username=employee -d password='Peopleos@123' \
  | python3 -c 'import sys,json;print(json.load(sys.stdin)["access_token"])')

curl -s http://localhost:9080/api/me -H "Authorization: Bearer $TOKEN"
```

Token sống **15 phút**. Grant `password` chỉ để thử; ứng dụng thật dùng Authorization Code + PKCE như People Workspace.

<TabItem value="js" label="JavaScript">

```js title="lib/api.js"
export async function api(path, {method = 'GET', body, token} = {}) {
  const res = await fetch(`http://localhost:9080/api${path}`, {
    method,
    headers: {Authorization: `Bearer ${token}`, 'Content-Type': 'application/json'},
    body: body ? JSON.stringify(body) : undefined,
  });
  const data = res.status === 204 ? null : await res.json();
  if (!res.ok) throw new Error(data?.detail ?? res.statusText);
  return data;
}
```

<TabItem value="py" label="Python">

```python
import requests

def api(path, token, method="GET", body=None):
    r = requests.request(method, f"http://localhost:9080/api{path}", json=body,
                         headers={"Authorization": f"Bearer {token}"})
    if not r.ok:
        raise RuntimeError(r.json().get("detail", r.reason))
    return r.json() if r.content else None
```

## Hiệu ứng phụ của mỗi thao tác ghi

Khi một thao tác ghi thành công, BFF thường:

1. Ghi **audit log** (ví dụ `LEAVE.APPROVED`) vào chuỗi băm bất biến.
2. Tạo **thông báo** cho người liên quan và đẩy qua [WebSocket](../realtime.mdx).
3. Phát sự kiện **NATS** `peopleos.events.<kind>`.
4. Với PaaS: thay đổi ở bảng `employees`, `contracts`, `leave_requests`, `payrolls` sinh [webhook](../platform/webhooks.mdx) cho developer.
